# VitalHealth Solutions - Clinic Appointment & Patient API

## Contexto de la Organización
VitalHealth Solutions ha desarrollado una aplicación web y API ligera para gestionar citas médicas, historiales básicos de pacientes y notificaciones de atención en red de clínicas. Antes de liberar una nueva actualización para los consultorios asociados, el equipo de tecnología ha solicitado una auditoría preliminar de seguridad debido a sospechas sobre malas prácticas de desarrollo y posibles vulnerabilidades en el repositorio.

## Objetivo de la Fase 1
El alumno debe realizar un análisis preliminar y un plan de auditoría **sin ejecutar herramientas de escaneo todavía**, revisando la estructura del código y los archivos de configuración para identificar los riesgos esperados.
